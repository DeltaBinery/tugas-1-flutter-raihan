## Panduan Setup Project
1. Buka terminal dan arahkan ke direktori proyek (`cd tugas4mobile`).
2. Jalankan perintah `flutter pub get` untuk mengunduh semua *dependencies*.
3. Sambungkan perangkat fisik atau jalankan emulator Android/iOS.
4. Jalankan aplikasi menggunakan perintah `flutter run`.

## Menjalankan Server Lokal & Import Database MySQL
*(Catatan: Requirement dokumentasi disiapkan untuk integrasi backend selanjutnya)*
1. Aktifkan layanan Apache dan MySQL melalui panel kontrol Laragon atau XAMPP.
2. Buka terminal pada direktori backend (jika ada) dan jalankan server lokal dengan perintah `php artisan serve`.
3. Buka aplikasi manajemen database seperti HeidiSQL atau phpMyAdmin.
4. Buat database baru (misalnya: `db_katalog_app`).
5. Lakukan *import* file `.sql` yang relevan ke dalam database yang baru dibuat tersebut.
