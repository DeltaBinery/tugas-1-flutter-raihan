## Panduan Setup Project
1. Buka terminal dan arahkan ke direktori proyek (`cd tugas5mobile`).
2. Jalankan perintah `flutter pub get` untuk mengunduh semua *dependencies*.
3. Sambungkan perangkat fisik atau jalankan emulator Android/iOS.
4. Jalankan aplikasi menggunakan perintah `flutter run`.

## Menjalankan Server Lokal
1. Aktifkan layanan Apache dan MySQL melalui control panel Laragon atau XAMPP.
2. Buka terminal pada direktori backend (jika ada) dan jalankan server lokal dengan perintah `php artisan serve`.
3. Akses server melalui browser (default: `http://localhost:8000`).

## Panduan Import Database MySQL
1. Buka aplikasi manajemen database seperti HeidiSQL atau phpMyAdmin.
2. Buat database baru (misalnya: `db_katalog_app`).
3. Buka/pilih database yang baru saja dibuat tersebut.
4. Pilih opsi **Import** atau **Load SQL File** lalu pilih file `.sql` milik proyek untuk dieksekusi.
